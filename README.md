# sec-header-checker

Консольная утилита проверяет, отдаёт ли сайт пять критических HTTP-заголовков безопасности, и печатает цветной отчёт с оценкой от **A** до **F**.

Проверяются:

| Заголовок | Зачем он нужен |
| --- | --- |
| `Content-Security-Policy` | Ограничивает, откуда страница может грузить скрипты и другие ресурсы |
| `Strict-Transport-Security` | Просит браузер ходить на сайт только по HTTPS |
| `X-Frame-Options` | Мешает встроить страницу в чужой фрейм |
| `X-Content-Type-Options` | Запрещает браузеру угадывать MIME-тип |
| `Referrer-Policy` | Ограничивает, какой `Referer` уходит на другие сайты |

Оценка считается по числу заголовков с непустым значением:

| Найдено | Оценка |
| --- | --- |
| 5 | A |
| 4 | B |
| 3 | C |
| 2 | D |
| 1 | E |
| 0 | F |

Утилита смотрит только на факт наличия. Содержимое заголовка показывается в отчёте, но не повышает и не понижает букву.

## Требования

- Python 3.11 или новее
- Доступ в сеть до проверяемого сайта

## Установка

Из корня проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

На macOS и Linux активация другая: `source .venv/bin/activate`, дальше команды те же через `python`.

## Запуск

```powershell
py checker.py https://example.com
```

Свой таймаут в секундах (от 1 до 60):

```powershell
py checker.py --timeout 5 https://example.com
```

Тот же таймаут можно задать через окружение. Скопируйте шаблон и уберите комментарий у строки:

```powershell
Copy-Item .env.example .env
```

```text
REQUEST_TIMEOUT=15
```

Флаг `--timeout` важнее значения из `.env`. Ключей, токенов и паролей у утилиты нет: не записывайте их в код и не добавляйте в URL. Файл `.env` уже указан в `.gitignore`.

Пример отчёта:

```text
Проверка заголовков безопасности
Запрошен: https://example.com
Итог:     https://example.com/
Оценка:   F  (0/5)

Заголовок                    Статус   Значение
---------------------------- -------- ------------------------
Content-Security-Policy      НЕТ      ограничивает источники скриптов и других ресурсов
Strict-Transport-Security    НЕТ      удерживает браузер на HTTPS
X-Frame-Options              НЕТ      мешает встроить страницу во фрейм
X-Content-Type-Options       НЕТ      запрещает браузеру угадывать MIME-тип
Referrer-Policy              НЕТ      ограничивает, какой Referer уходит на другие сайты
```

Зелёным отмечены оценка A/B и статус `ЕСТЬ`, жёлтым — C/D, красным — E/F и статус `НЕТ`.

## Как устроен запуск

1. Адрес проверяется до запроса: только `http` и `https`, без логина и пароля, без управляющих символов, кавычек и `..`.
2. Утилита делает один GET, следует не больше чем по пяти редиректам и читает только заголовки.
3. Итоговый адрес после редиректа проверяется так же, как исходный.
4. В терминал попадает очищенный текст, без управляющих символов из ответа сайта.

Адрес не открывается как локальный файл и не подставляется в команды оболочки или SQL.

## Коды выхода

| Код | Когда |
| --- | --- |
| 0 | Отчёт напечатан |
| 1 | Сайт не ответил: сеть, TLS или таймаут |
| 2 | Некорректный URL или таймаут вне диапазона 1–60 |

Справка по аргументам: `py checker.py --help`.
